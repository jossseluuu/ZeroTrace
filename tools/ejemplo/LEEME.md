# Edición de referencia

Estos archivos son el **formato de referencia** que sigue cada edición diaria. No se publican: el generador solo lee `data/`.

- `edicion.es.json` y `edicion.en.json`: estructura completa de una edición (ES y EN).
- `alertas.json`: estructura de las alertas del semáforo, tal como se guardan en `data/alertas.json`.

Los datos son de ejemplo (noviembre de 2026) y **no** deben copiarse a `data/`: las alertas que contienen no se han notificado.
