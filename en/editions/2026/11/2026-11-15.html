Your PC shouldn't run on the admin account every day

Why the account you browse, read email and game on should be a standard account, how to switch without locking yourself out, and what it won't fix.

In a nutshell

Most home Windows PCs have a single account, the one created the first time the computer was turned on, and that account is an administrator: it can install software, change any setting and reach every user's files. That's convenient, but it also means any program you say "yes" to can do the same.

A handles everything normal: browsing, email, office work, games, video calls. When something needs admin rights, Windows asks for the password or PIN of an administrator account. That speed bump is the whole point: a program that sneaks in can't install itself system-wide unless someone types that credential.

Microsoft says so in its own help pages: it's safer to have fewer administrators and use standard user accounts for day-to-day activities. On a family computer, that means one admin account that barely gets used and a standard account for each person.

The essentials

  • An admin account can change everything, and so can whatever runs under it.
  • With a standard account you do the same things as always; you only get asked for a credential to install software or change system settings.
  • Before downgrading your account, create a second admin account and make sure you know its password.
  • It's not antivirus: malware can still steal what's in your own account. Updates and common sense still matter.

Real-world risk

Likelihood: medium

Downloading software from a site that isn't the official one, a "crack," or a fake installer advertised in search results is a common mistake in any household, especially on shared computers.

Impact: high

With admin rights, malware can turn off protections, set itself to start every time and affect every account on the computer, not just yours.

How it works

What actually differs between the two

Windows has two account types: Administrator and Standard User. Since Windows Vista, even administrators normally work with reduced rights thanks to (UAC). When something asks for more, Windows shows a prompt: an administrator just clicks Yes, while a standard user has to type an administrator's password or PIN.

It sounds like a small difference, but it isn't. Clicking "Yes" happens on autopilot; typing another account's credential makes you stop. And if only one person in the household knows that credential, nobody else can install anything system-wide without it.

The caveat Microsoft admits

In its technical documentation, Microsoft explains that UAC's same-desktop elevation isn't a security boundary: a program already running in your session can try to hijack it. That's why it concludes that, from a security standpoint, a UAC-"protected" administrator should be considered the equivalent of an administrator.

By contrast, it does treat the separation between a standard user session and a different administrator account as a security boundary. That's the underlying technical reason to use a standard account every day instead of simply trusting UAC prompts.

What's new: Administrator protection

Windows 11 includes a feature called Administrator protection, available with the August 2026 update KB5120998 on Home, Pro, Enterprise and Education editions. It's off by default. When turned on, every admin action has to be approved with Windows Hello (fingerprint, face or PIN) and runs under a hidden, separate account that Windows creates and discards for that task.

Microsoft notes that the toggle in the Windows Security app is still a preview that will roll out to everyone gradually, and that a restart is required. It also advises against turning it on for devices that require Hyper-V, among other cases. For a home PC, a standard account remains the simple, proven step.

What a standard account doesn't do

Microsoft also warns about this: malware can be written not to need admin rights and to work only inside your user profile. A browser password stealer or a program that encrypts your documents can run just fine under a standard account, because that data is yours.

What you do stop is anything that touches the whole system: installing drivers or services, turning off protections, reaching other accounts' files. It's one more layer, not a force field, and it works alongside keeping Windows updated and having backups.

What an attack looks like

  1. The bait

    You search for a free app and the top result is an ad leading to a site that looks almost identical to the official one. You download the installer.

  2. The installer

    When you open it, Windows shows the UAC prompt. On an admin account, clicking "Yes" is all it takes for the program to install with full rights.

  3. What it does with those rights

    It can install itself as a service that always starts, try to turn off protections and reach the files of every account on the computer.

  4. On a standard account

    The same prompt asks for an administrator's password or PIN. If you don't have it handy, or you stop to wonder why a "PDF viewer" needs system-wide access, the chain breaks.

  5. What's left

    If the program doesn't ask for elevation and only works inside your profile, it can still steal your stuff. That's why a standard account goes together with downloading only from official sites and keeping Windows updated.

What an attacker can and can't do

Can

  • Steal what's in your own account (passwords saved in the browser, documents) with a program that never asks for elevation.
  • Trick you into typing the admin password if you know it and don't stop to think.
  • Exploit an unpatched Windows flaw to gain privileges if the computer isn't up to date.
  • Act with full rights if an admin account is still used every day on the computer.

Can't

  • Install a program or service system-wide from a standard account without an administrator's credential.
  • Read or change other accounts' files from a standard account.
  • Change system security settings that require admin rights.
  • Gain admin rights just because someone clicks "Yes": on a standard account there's no "Yes" button without a credential.

What to do

Check which account type you use

  • Impact: medium
  • Effort: low
  • ⏱ 1 min
  • For: everyone

If it says "Administrator" under your name, anything you run can get full rights with a click.

Windows 11

  1. Open Settings > Accounts > Your info.
  2. See whether Administrator appears under your name.

Create a backup administrator account

  • Impact: high
  • Effort: low
  • ⏱ 5 min
  • For: everyone

This is a must before downgrading your own account: a standard account can't grant itself admin rights, and without another administrator you'd be unable to install anything.

Windows 11

  1. Go to Settings > Accounts > Other users and, next to Add other user, select Add account.
  2. Create the account, then under Account options select Change account type and choose Administrator.
  3. Sign out, sign in with it once to confirm the password works, and save it in your password manager.

Switch your everyday account to standard

  • Impact: high
  • Effort: low
  • ⏱ 3 min
  • For: everyone

You keep your files, apps and settings. The only change is that installing software or touching the system will ask for the backup account's credential.

Windows 11

  1. Sign in with the backup administrator account.
  2. In Settings > Accounts > Other users, expand your usual account, select Change account type and choose Standard User.
  3. Sign back in with your usual account and make sure everything works.

A standard account for each person at home

  • Impact: medium
  • Effort: medium
  • ⏱ 10 min
  • For: everyone

On a shared computer, everyone gets their own standard account: their files stay separate and nobody installs anything without the admin credential. For kids, Microsoft suggests adding them from Accounts > Family.

Windows 11

  1. In Settings > Accounts > Other users, select Add account for each person and leave the type as Standard User.

Don't set UAC to "Never notify"Deep-dive level

  • Impact: medium
  • Effort: low
  • ⏱ 1 min
  • For: advanced

At that level, Windows grants admin rights without asking. Microsoft explicitly says the setting isn't recommended.

Windows 11

  1. Search Start for Change User Account Control settings.
  2. Make sure the slider isn't at the bottom; the default level is the right one.

Turn on Administrator protection if you already see itDeep-dive level

  • Impact: medium
  • Effort: low
  • ⏱ 3 min
  • For: advanced

For people who need to work as administrators. Microsoft is rolling it out gradually and doesn't recommend it if you use Hyper-V or share files across profiles.

Windows 11

  1. Open the Windows Security app, go to Account protection and find the Administrator protection setting.
  2. Turn it on and restart when prompted.

Check it yourself

Does your account say "Standard User"?

In Settings > Accounts > Your info, "Administrator" should no longer appear under your name.

Do you get asked for a credential when installing?

When you open an installer, the UAC prompt should ask for the backup account's password or PIN, not just a "Yes."

Can you sign in to the backup account?

Test it today, not the day you need it. And don't reuse your everyday account's password for it.

How many administrators does the computer have?

Under Other users, check each account's type. At home, one is ideal, two at most.

What you don't need to do

Disabling the admin account altogether

You need it to install software and driver updates. The point is not to use it every day, not to get rid of it.

Reinstalling Windows to start fresh

Changing the account type doesn't delete anything and can be undone in a minute from the backup account.

Buying an app to "manage permissions"

Windows already has everything you need: account types, UAC and, on Windows 11, Administrator protection.

Stressing when you have to type the credential now and then

On a home PC you install something every so often. If it's asking very often, it's worth asking which program keeps requesting it.

Myth and reality

What people think

"I'm an admin, but UAC warns me, so I'm just as protected."

What actually happens

Microsoft explains that UAC's same-desktop elevation isn't a security boundary and that a UAC-protected administrator should be considered the equivalent of an administrator. The real separation is a standard account for daily use and a different account for administration.

Microsoft: How to disable User Account Control (UAC) on Windows Server (More information section)

For technical readers

Filtered token and Admin Approval Mode

At sign-in, a member of the Administrators group gets two tokens: a filtered, deprivileged one used to launch Explorer and everything you open, and a full one used only after elevation. Child processes inherit the parent's token. A standard user only has the filtered token, and elevation requires another account's credentials (the credential prompt), while an administrator only has to consent (the consent prompt). The secure desktop makes it harder for another process to spoof or click the prompt, but Microsoft doesn't treat same-desktop elevation as a security boundary.

Administrator protection under the hood

With Administrator protection, elevation doesn't reuse the user's own full token: Windows creates an isolated token from a hidden, system-generated, profile-separated account and destroys it when the process ends. There are no auto-elevations, every operation needs interactive Windows Hello authorization, and events 15031 (elevation approved) and 15032 (denied or failed) are logged under the Microsoft-Windows-LUA ETW provider. It's configured with the User Account Control: Configure type of Admin Approval Mode policy (in secpol.msc or Group Policy) or via Intune/CSP; Windows 11 security baselines turn it on by default starting with the October 2026 update.

For developers

Least privilege applies to your software too: have the installer request elevation only if it writes to system locations, make the app work without privileges, and don't assume the elevated profile is the same as the regular one. With Administrator protection, settings saved in the elevated profile don't carry over to the regular session, and the regular session's network drives and single sign-on aren't available in the elevated one.

Glossary

Standard account
A Windows account type that can use the computer normally but needs an administrator's password or PIN to install software or change system settings.
User Account Control (UAC)
A Windows feature that runs programs with reduced rights and shows a confirmation prompt when something needs administrator privileges.
